# RIG — the shell

Installable glass for [RIG](https://bmhsolutions3711.github.io/rig/). HTML, CSS, JS, a manifest, a service worker.

**There is no data here and there never will be.** The book lives on the Pro, behind Tailscale, token-gated. This page is glass.

## Connect

Once, from the Pro's `start.sh` output:

`https://bmhsolutions3711.github.io/rig/#cfg={"api":"https://…ts.net:8700","token":"…"}`

Origin and token land in `localStorage`. The hash is scrubbed. `#reset` clears them.
